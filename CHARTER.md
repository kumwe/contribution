# Kumwe Contribution

Kumwe Contribution owns neutral contributor identities, declarative definition contracts, explicit bounded surface
identifier policies and deterministic owner-scoped data registries. It is independently usable with PHP alone under
`Kumwe\Contribution`.

The host owns trust, authorization, lifecycle admission/removal, runtime generation, manifest reconciliation,
executable implementation objects, routes, rendering, persistence and recovery. An owner value is never a security
credential. A registry is a local data collection and has no active-runtime authority.

No SDK, App, container, Canonical JSON, database or delivery dependency. SDK is the outer toolkit that must adopt
these canonical types separately. Six public types form one coherent boundary. No empty ConfigProvider:
owners/policies are immutable direct values; registries are explicitly created mutable instances per composition.
